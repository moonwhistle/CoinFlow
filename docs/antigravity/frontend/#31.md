# Issue #31 Frontend Integration

## 무엇을 바꿨는지
- **프로젝트 초기화**: `frontend` 디렉토리에 Vite + React + TypeScript 기반 프로젝트 생성.
- **스타일링 설정**: Tailwind CSS v4 설치 및 설정 (`@tailwindcss/postcss` 사용).
- **의존성 추가**:
  - `lightweight-charts`: 고성능 차트 라이브러리.
  - `classnames`: 조건부 스타일링 유틸리티.
- **구조 및 스켈레톤**:
  - `src/pages`, `src/components`, `src/services` 등으로 폴더 구조화.
  - `Home.tsx` 구현: 반응형 레이아웃 및 차트/상태 표시용 플레이스홀더 적용.
- **리팩터링 (Mentor Feedback)**:
  - `src/constants/ui.ts` 분리: `Home.tsx`의 하드코딩된 UI 텍스트 상수화.
  - `@/` Alias 설정: `vite.config.ts` 및 `tsconfig.app.json`에 절대 경로 별칭 추가.

## 왜 바꿨는지
- **성능 및 반응성**: 비트코인 시세 및 차트 등 실시간 데이터 처리가 핵심이므로, 가볍고 빠른 Vite와 렌더링 성능이 우수한 `lightweight-charts`를 선정함.
- **개발 효율성**: Tailwind CSS를 통해 일관된 디자인 시스템을 빠르게 적용하고 유지보수성을 높임.
- **유지보수성 강화**: 
  - 멘토 피드백을 반영하여 Magic String을 제거하고 상수로 관리.
  - 깊은 경로(`../../`) 사용을 방지하여 코드 가독성 향상.

## 어떻게 검증했는지
- **빌드 테스트**: `npm run build` 명령어를 통해 TS 컴파일 및 번들링이 에러 없이 완료됨을 확인.
- **로컬 실행**: `npm run dev`로 개발 서버를 띄워 홈 화면이 정상적으로 렌더링되며, 텍스트가 정상 출력됨을 확인.
